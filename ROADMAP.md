# Roadmap & Changelog проекта Desk OLED

В рамках модернизации прошивки для **ESP32-C3 SuperMini** и OLED 0.91″ (SSD1306 128×32) были спроектированы и внедрены ключевые улучшения: управление одной кнопкой, плавные переходы, ночной режим, защита от выгорания, неблокирующие сетевые задачи FreeRTOS и оптимизация энергопотребления/температуры.

---

## Версия 0.5.0 — надёжность и управление

- Добавлен retry/backoff для сетевых обновлений: после ошибок интервалы повторов увеличиваются, чтобы не перегружать публичные API.
- Последние успешные погодные, AQI и валютные значения не затираются временной ошибкой сети.
- Добавлена блокировка фоновых запросов mutex-ом, чтобы веб-запрос и FreeRTOS-задача не выполнялись одновременно.
- Ошибки разделены по источникам: геокодирование, погода, AQI и курсы валют.
- Часовой пояс сохраняется по имени зоны, полученной при геокодировании (`Asia/Barnaul`, `Europe/Moscow` и т. п.).
- Веб-интерфейс защищён Basic Auth (`admin` / пароль из настроек).
- Для каждого слайда в веб-интерфейсе доступны порядок и длительность показа.
- Перерисовка OLED ограничена изменением секунды, слайда или входных данных.
- Pixel Shift теперь применяет горизонтальное смещение к framebuffer перед выводом.
- В диагностический API добавлены часовой пояс, свободная память и отдельные ошибки источников.
- Последние значения погоды, AQI и валют сохраняются в NVS и доступны сразу после перезагрузки.

Начальный пароль веб-интерфейса: `deskadmin`. Его следует изменить сразу после первого входа.

## Версия 0.6.0 — читаемость OLED

- Часы центрированы и отображаются крупнее, секунды и год убраны с главного экрана.
- Текущая погода переразложена на крупную температуру, короткое состояние и компактную строку города/влажности/ветра.
- Прогноз и осадки объединены в двухстрочный слайд с условной подписью «Без дождя».
- Длинные строки подгоняются под ширину 128 пикселей, добавлена обрезка UTF-8 текста.
- Восход и закат переводятся из AM/PM в 24-часовой формат.
- AQI, валюты, комнатный климат и статус получили более строгую иерархию размеров текста.

---

## Версия 0.7.0 — данные и эксплуатация

- Для кэша добавлен epoch timestamp: возраст данных сохраняется после перезагрузки и не превращается в ошибочные миллионы минут.
- Вероятность и сумма осадков теперь собираются из одного дневного набора часовых прогнозов wttr.in.
- Геокодирование выполняется только при изменении города или при первичном подключении.
- В диагностике отображаются отдельные ошибки погоды, AQI и курсов.
- Сканирование Wi-Fi вынесено из формирования главной страницы, поэтому веб-интерфейс не должен ждать завершения сканирования.

---

## Версия 0.8.0 — редактор макетов OLED

- Добавлена desktop-first страница `/layout` с увеличенным предпросмотром 128×32.
- Элементы экранов можно перемещать мышью и редактировать по координатам X/Y.
- Добавлены выбор шрифта, выравнивание, видимость и сохранение макета в NVS.
- Редактор работает с динамическими элементами: время, дата, температура, AQI, валюты, восход/закат и другие данные не превращаются в статический текст.
- Для каждого экрана есть сброс к заводскому макету.

## Версия 0.4.0

- Убран обязательный API-ключ Яндекс.Погоды и поле ключа из веб-интерфейса.
- Прогноз переведён на бесплатный публичный endpoint `wttr.in`:
  - текущая температура;
  - влажность;
  - скорость ветра;
  - минимум/максимум дня;
  - вероятность и количество осадков;
  - восход и закат.
- Добавлен разбор JSON `format=j1` с фильтром ArduinoJson: ответ около 40 КБ не загружается целиком в структуру JSON.
- Убрана фаза луны из экранов: слайд солнца теперь показывает только восход, закат и город.
- Отдельный экран дождя объединён с прогнозом и исключён из плейлиста, чтобы не дублировать информацию.
- Увеличен шрифт часов, убраны секунды с главного экрана, сокращены погодные подписи.
- В веб-интерфейсе увеличены поля для мобильного ввода и удалён ненужный пункт настройки ключа Яндекс.Погоды.
- Проверено на ESP32-C3 в домашней сети: HTTP 200, данные Бийска успешно получены.
- Сохранён Open-Meteo только для геокодирования города и получения AQI.

Ограничение: wttr.in не требует ключа, но является публичным сервисом без гарантированного SLA. При частых запросах или недоступности сервиса нужна резервная стратегия или локальный прокси-кэш.

### 3. Ночной режим (Night Mode) & Автояркость
- **Файлы**: [`src/display.cpp`](file:///Users/dmitrijsibanov/Desktop/My_projects.nosync/ESP32/desk-oled/src/display.cpp), [`src/portal.cpp`](file:///Users/dmitrijsibanov/Desktop/My_projects.nosync/ESP32/desk-oled/src/portal.cpp), [`src/fetchers.cpp`](file:///Users/dmitrijsibanov/Desktop/My_projects.nosync/ESP32/desk-oled/src/fetchers.cpp)

  - Раздельная настройка дневной яркости (`contrast`, по умолч. 160) и ночной яркости (`nightContrast`, по умолч. 28).
  - Опция **«Ночью только часы»** (`nightClockOnly`): ночью слайды не мелькают перед глазами, остаётся только тусклый циферблат с часами.

### 4. Защита OLED от выгорания (Burn-in Pixel Shifting)
- **Файл**: [`src/display.cpp`](file:///Users/dmitrijsibanov/Desktop/My_projects.nosync/ESP32/desk-oled/src/display.cpp)
- **Функционал**:
  - Монохромные экраны SSD1306 подвержены деградации люминофора при длительном статическом свечении.
  - Каждые 10 минут система незаметно циклически смещает область отрисовки на 1 пиксель по осям X/Y `(0,0) -> (1,0) -> (1,1) -> (0,1)`. Включается/выключается галочкой в веб-интерфейсе.

### 5. Асинхронные сетевые запросы во FreeRTOS
- **Файл**: [`src/main.cpp`](file:///Users/dmitrijsibanov/Desktop/My_projects.nosync/ESP32/desk-oled/src/main.cpp)
- **Функционал**:
  - Раньше тяжелые HTTPS-запросы к погодному сервису и ЦБ РФ (`HTTPClient`) полностью подвешивали главный цикл `loop()` на 1–3 секунды — часы замирали.
  - Создана фоновая задача FreeRTOS (`backgroundFetchTask`) со стеком 12 КБ для HTTPS/mbedTLS.
  - Все сетевые обновления погоды, качества воздуха и курсов валют выполняются в фоне. Основной цикл `loop()` продолжает плавно рендерить часы с тикающими секундами и анимациями без малейших задержек.

---

### 6. Снижение энергопотребления и нагрева ESP32-C3
- **Файлы**: [`platformio.ini`](file:///Users/dmitrijsibanov/Desktop/My_projects.nosync/ESP32/desk-oled/platformio.ini), [`src/main.cpp`](file:///Users/dmitrijsibanov/Desktop/My_projects.nosync/ESP32/desk-oled/src/main.cpp)
- **Функционал**:
  - Частота CPU понижена со 160 МГц до **80 МГц** (`board_build.f_cpu = 80000000L`). Для OLED 128×32 этого с избытком, при этом чип становится холоднее на ~8–12°C.
  - В текущей версии Wi-Fi sleep отключён через `WiFi.setSleep(false)`, чтобы не ухудшать стабильность длинных HTTPS-запросов и фоновых обновлений.
  - Критически важно для работы датчика BME280 — холодная плата больше не искажает комнатную температуру.
