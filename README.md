# Desk OLED — прошивка для ESP32-C3 SuperMini

Настольный индикатор на OLED 0.91″ (128×32, I2C): **время, дата, погода, курсы ЦБ РФ**, плюс качество воздуха и восход/закат. На маленьком экране кадры **сменяются по очереди**, интервал задаётся в веб-интерфейсе. Компоновка оптимизирована под читаемость: крупные значения показываются отдельно, а прогноз и осадки объединены.

При первом включении (или если домашняя сеть недоступна) плата поднимает точку доступа. С телефона можно указать Wi‑Fi, город и какие слайды показывать.

## Что нужно

| Штука | Заметки |
| --- | --- |
| ESP32-C3 SuperMini | USB‑C к Mac |
| OLED 0.91″ I2C | Обычно SSD1306, 128×32, адрес `0x3C` |
| 4 провода | Dupont, лучше 3.3 V, не 5 V |

Питание дисплея только с **3.3 V**. Пять вольт на VCC часто убивают модуль.

## Подключение OLED

На SuperMini **нельзя** вешать I2C на GPIO8 и GPIO9: GPIO8 — адресный светодиод, GPIO9 — кнопка BOOT (strapping).

| OLED | ESP32-C3 SuperMini | Комментарий |
| --- | --- | --- |
| VCC / VIN | **3V3** | не 5V |
| GND | **GND** | общий минус |
| SDA | **GPIO6** | данные I2C |
| SCL | **GPIO7** | тактирование I2C |

Порядок пинов на модуле OLED бывает разный (`GND-VCC-SCL-SDA` или `VCC-GND-SCL-SDA`). Смотрите **подписи на плате**, не цвет проводов.

```
 OLED 0.91"                 ESP32-C3 SuperMini
┌──────────┐                ┌─────────────────┐
│ VCC  ────┼── 3.3V ───────│ 3V3              │
│ GND  ────┼── GND  ───────│ GND              │
│ SCL  ────┼── GPIO7 ──────│ GPIO7            │
│ SDA  ────┼── GPIO6 ──────│ GPIO6            │
└──────────┘                │ GPIO9 = BOOT     │
                            │ USB-C → Mac      │
                            └─────────────────┘
```

Пины заданы в `include/pins.h`. Если ваш модуль не на `0x3C`, поменяйте `OLED_ADDR`.

## Как прошить с Mac

1. Установите [PlatformIO Core](https://platformio.org/install/cli) или расширение PlatformIO в Cursor/VS Code.
2. Подключите плату USB‑C. Если macOS не видит порт, на SuperMini часто нужен драйвер USB‑CDC — после прошивки с флагами `ARDUINO_USB_CDC_ON_BOOT` порт появляется как `/dev/cu.usbmodem*`.
3. Из папки проекта:

```bash
cd desk-oled
pio run -t upload
pio device monitor
```

Если загрузчик не ловится: **зажмите BOOT, нажмите RESET, отпустите RESET, затем отпустите BOOT**, сразу запустите `pio run -t upload`.

После старта прошивки BOOT больше не держите — иначе плата снова уйдёт в download mode.

## Первый запуск и веб-настройка

1. На OLED: `DeskC3-XXXX` и пароль `desk1234`, адрес `http://192.168.4.1`.
2. На телефоне подключитесь к этой сети (интернета на ней нет — это нормально).
3. Откроется портал, либо вручную зайдите на `http://192.168.4.1`.
4. Выберите домашнюю Wi‑Fi, введите пароль, укажите **город** (как в жизни: `Москва`, `Bangkok`, `Chiang Mai`).
5. Задайте интервал слайдов (по умолчанию 6 секунд) и какие экраны включить.
6. «Сохранить и подключить» — плата перезагрузится, найдёт координаты города (Open‑Meteo), синхронизирует время по NTP.

Потом интерфейс доступен уже в домашней сети: `http://<IP платы>/` (IP показан на слайде «статус»).

### Снова войти в настройку

- Удерживать **BOOT ≈ 3 секунды после загрузки** прошивки — снова поднимется точка доступа (пароль Wi‑Fi не стирается, пока не нажмёте сброс).
- В веб-UI: «Только точка доступа» или «Заводской сброс».
- Если домашняя сеть не поднимается ~25 секунд — плата сама откроет AP.

## Откуда данные

| Экран | Источник | Как часто |
| --- | --- | --- |
| Время и дата | NTP, часовой пояс из ответа погоды | при подключении и раз в 6 ч |
| Погода | [wttr.in](https://wttr.in/), без ключа | 15 мин |
| Мин/макс, осадки | тот же прогноз, JSON `format=j1` | 15 мин |
| Курсы USD / EUR / CNY | ЦБ РФ, `cbr-xml-daily.ru` | 60 мин |
| AQI и PM2.5 | Open-Meteo Air Quality | 15 мин |
| Восход/закат | wttr.in, раздел `astronomy` | 15 мин |
| Луна | считается на плате по дате | каждый показ |

Город геокодируется через Open-Meteo (есть русские названия), а погодные данные берутся с wttr.in. Время на экране — **локальное для этого города**, не время Mac. Для прогноза не нужен API-ключ.

### Если погода не загружается

Плата должна иметь доступ к `wttr.in` по HTTPS. Проверить состояние можно на странице диагностики `/diag` или командой `s` через Serial. Принудительное обновление выполняется командой `f`. В логе успешный запрос выглядит так:

```text
[HTTP] GET https://wttr.in/52.5342,85.1966?format=j1
[HTTP] Response: 200
[WX] wttr OK: temp=... humidity=... wind=...
```

Ответ wttr.in довольно большой (около 40 КБ), поэтому прошивка разбирает только необходимые поля через фильтр ArduinoJson.

HTTPS без проверки сертификата (`setInsecure`) — сознательно, чтобы не тащить кучу корневых CA во flash. Для домашней игрушки этого достаточно.

## Слайды на 128×32

Одновременно всё не влезает, поэтому ротация:

1. Крупные часы + день недели и дата  
2. Температура, кратко погода, город, влажность, ветер  
3. Мин/макс сегодня, вероятность и количество осадков  
4. Три курса ЦБ к рублю  
5. Европейский AQI и PM2.5  
6. Восход и закат  
7. Комнатный климат (опционально)  
8. IP, RSSI, интервал, город (опционально)  

Отдельный экран дождя и фаза луны убраны: дождь показывается вместе с прогнозом, а экран восхода/заката оставлен без лунной фазы. Ненужные экраны выключаются галочками в UI.

## Идеи, которые уже можно добавить следующей итерацией

- **Кнопка «следующий слайд»** на свободный GPIO (например GPIO4) — листать вручную, не ждать таймер.
- **Ночной режим**: после заката снизить контраст или показывать только часы.
- **Другие валюты** (THB, KZT) — ЦБ их тоже отдаёт.
- **Датчик BME280** на ту же шину I2C: температура/влажность в комнате рядом с улицей.
- **Home Assistant / MQTT** — публиковать те же цифры.
- **Локальный кэш на NVS**, чтобы после ребута сразу рисовать прошлые значения, пока качается сеть.
- **Wokwi-симуляция** для отладки OLED без платы.

Если захотите второй дисплей побольше (1.3″ SH1106 128×64), логику слайдов можно оставить, поменяется только драйвер U8g2.

```
desk-oled/
  platformio.ini      плата, USB-CDC, U8g2, ArduinoJson
  include/pins.h      GPIO6/7, BOOT, адрес OLED
  include/settings.h  NVS: Wi-Fi, город, слайды
  src/main.cpp        старт, ротация, BOOT, reconnect
  src/portal.cpp      AP + captive portal + web UI
  src/display.cpp     кадры 128×32
  src/fetchers.cpp    геокод, погода, AQI, ЦБ
  src/settings.cpp    Preferences
```
